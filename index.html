Creator Intelligence

A free, local-first research and planning tool for original video production. A personal project by Steven Patrick Buglione.

Purpose

Creator Intelligence brings official YouTube records, owner-authorized channel reports and original production drafts into a private workspace. It supports evidence-linked ideas, script and thumbnail briefs, versioned blueprints, and an owner-reviewed handoff to an existing production pipeline.

Private deployment

The current application is intended for one individual user. This page is documentation, not a hosted analytics service or public MCP endpoint. The software is a release candidate. Some integrations are still being verified. Custom API-derived scoring and extended public statistical retention are not enabled pending YouTube permission and implementation.

YouTube API Services

Public records come from official YouTube APIs. Owner reports require the channel owner's Google authorization. Creator Intelligence does not provide access to another creator's private analytics and does not publish videos. Existing publishing tools remain separate.
