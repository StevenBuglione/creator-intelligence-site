Privacy and data controls

Last updated: 16 October 2026. Operator: Steven Patrick Buglione, acting as an individual. This policy describes the current personal release candidate.

Data and purpose

Creator Intelligence uses YouTube API Services to obtain public channel and video metadata and statistics, and reports for the channel that its owner authorizes. It also stores original ideas, scripts, reference links, production blueprints and delivery records. The purpose is private research and planning for original videos, not advertising, data resale or audience profiling.

Storage and retention

The application stores its data in a local PostgreSQL database. OAuth tokens are encrypted at rest, and credentials are held outside the source repository. Public API metadata and statistics currently expire after 30 days. Owner reports are subject to continuing authorization checks. Approval-gated extended statistical retention is not active. Original drafts persist until deletion; managed encrypted draft backups normally expire after seven days and exclude API caches and Google tokens.

Sharing and AI

Connecting Claude permits requested MCP records to be sent to the connected Claude client and processed by its provider under that account's terms and settings. Therefore local storage does not imply that all processing stays on the device. Those settings must be verified before live sharing. The application itself has no model-training workflow. An optional local model performs inference. Approving production delivery sends the reviewed blueprint and its references to the configured ContentOS receiver. Credentials are not included in tool results or production blueprints.

Deletion and Google authorization

Settings provides local export, disconnect and deletion. Local deletion affects this application's stored data, not videos on YouTube. Managed draft backups are removed on application data deletion; separately downloaded exports and manual backups remain the owner's responsibility. Local disconnect removes this app's connection and owner reports but does not itself revoke the shared Google grant. A separately confirmed revocation control and Google Account permissions allow withdrawal of Google access. In the present shared-project prototype, revocation also affects existing publishing clients; a dedicated project is planned before the audit.

Cookies and external requests

The local UI uses a session cookie for authentication. There are no advertising cookies in the application. API requests reach Google; displaying official thumbnail references may make requests to Google image servers. This documentation website is hosted on GitHub Pages. The site includes no analytics scripts, external fonts or application cookies. GitHub logs and stores visitor IP addresses for security purposes. Opening the GitHub contact link uses GitHub under its own privacy terms.
